1Abstract

SecEngine is a full-stack, browser-based cybersecurity intelligence platform that delivers enterprise-grade web security assessment tools to any user without installation or authentication. The platform addresses three distinct but interconnected threat domains: HTTP security header auditing with SSL/TLS certificate validation, phishing URL detection through multi-factor heuristic analysis, and social-engineering message classification using natural language pattern matching.

Built on Python Flask with a zero-dependency vanilla JavaScript frontend, SecEngine processes scan requests server-side and returns structured JSON threat reports in real time. The web application features a modern, responsive cyber-themed interface inspired by industry leaders such as CrowdStrike and Cloudflare, delivering an enterprise-grade experience while remaining completely free and open to all users.

Keywords: Web Security, HTTP Security Headers, Phishing Detection, Social Engineering, SSL/TLS, Flask, Cybersecurity, Threat Intelligence, Heuristic Analysis, NLP Pattern Matching.

2Introduction & Problem Statement

2.1 Background

The modern web threat landscape has evolved significantly, with attackers increasingly leveraging misconfigured web servers, phishing campaigns, and social engineering to compromise individuals and organizations. Over 90% of successful cyberattacks begin with phishing, while a majority of public-facing web applications are deployed without critical HTTP security headers — leaving users vulnerable to cross-site scripting (XSS), clickjacking, MIME-type attacks, and man-in-the-middle (MITM) interception.

Despite the availability of individual security tools, there exists a gap for a unified, free, browser-based platform that consolidates web security auditing, URL threat analysis, and message-based social engineering detection into a single cohesive interface.

2.2 Problem Statement

🔓
Misconfigured Web Security
Millions of websites lack critical HTTP security headers (HSTS, CSP, X-Frame-Options), exposing users to XSS, clickjacking, and MITM attacks. No unified free tool exists to rapidly audit and remediate these gaps.
🎣
Phishing & URL Threats
Phishing URLs use brand impersonation, suspicious TLDs, and IP-based hosting. Non-technical users lack accessible tools to evaluate link safety before clicking.
📨
Social Engineering via Messages
Email and SMS phishing rely on urgency, fear, and financial lures to manipulate victims. Detecting these patterns requires NLP-level analysis not available in standard spam filters.
💰
Tool Accessibility Gap
Enterprise security tools are prohibitively expensive for individuals, students, and small organizations. A completely free, no-account alternative is needed to democratize cybersecurity.

4.2 Request–Response Data Flow

Step 1
User Input
User enters a URL or pastes message text and clicks scan. The frontend performs minimal client-side validation before submitting.
Step 2
AJAX Request
JavaScript sends a POST request to the appropriate Flask endpoint with a JSON payload ({"url":"..."} or {"text":"..."}).
Step 3
Server-Side Analysis
Flask normalizes the input, dispatches to the appropriate analysis module. For header scans an outbound HTTP request is made; for URL/text scans all processing is done locally.
Step 4
Scoring & Classification
The engine computes a numeric score, assigns a grade or risk level, and compiles a structured report with per-finding details and remediation snippets.
Step 5
Response Rendering
Flask returns JSON. JavaScript parses it and dynamically renders score gauges, animated bars, header checklists, risk badges, and toast notifications — no page reload.

6Module-Wise Implementation

Endpoint: POST /api/scan-headers

Performs a live HTTP GET request to the target domain and inspects response headers against OWASP-recommended security controls. Simultaneously opens a raw TCP/TLS socket to port 443 to extract X.509 certificate details.

7Security Analysis Algorithms

7.1 SSL Certificate Extraction

FUNCTION get_ssl_info(hostname):
  1. Create SSL context with trusted CA store
  2. Open TCP connection to hostname:443 (timeout 5s)
  3. Wrap with TLS handshake (SNI enabled)
  4. Extract X.509 cert via getpeercert()
  5. Parse notAfter → datetime → compute days_remaining
  6. Extract issuer organizationName from RDN sequence
  7. RETURN {valid, expires, days_remaining, issuer}
  ON EXCEPTION: RETURN {valid: False, error: str(e)}

7.2 Header Audit Scoring

score = 0
FOR each of 6 OWASP headers:
    IF header present in HTTP response: score += 10

IF ssl_info.valid == True: score += 40

grade = A+ if score>=90, A if >=80, B if >=70,
        C if >=60, D if >=50, else F

7.3 Phishing URL Risk Score

risk = 0
IF hostname matches raw-IP regex:        risk += 35
IF brand found in unofficial domain:     risk += 40
IF hostname ends with suspicious TLD:    risk += 25
IF phishing keywords in URL:             risk += 20
IF structural anomalies detected:        risk += 15
RETURN min(risk, 100)

13Conclusion

SecEngine successfully achieves its primary objectives: delivering a fully functional, free, and open-access cybersecurity intelligence platform that consolidates three distinct threat analysis capabilities — HTTP security header auditing, phishing URL detection, and social engineering message classification — into a single unified web application.

The project demonstrates practical application across multiple computer science domains: web development with Python Flask, applied cryptography through SSL/TLS certificate inspection, regex-based pattern matching for threat detection, RESTful API design, and enterprise-grade UI/UX engineering.

The platform's architecture — a stateless Flask backend with a zero-dependency JavaScript frontend — ensures it is lightweight, deployable in under 30 seconds, and accessible to individuals, students, security researchers, and small organizations who cannot afford commercial cybersecurity tools.

Project Status: Fully implemented and tested. All 3 API endpoints are operational, all 25 frontend structural checks pass, the custom SecEngine logo is integrated as the browser favicon, the scoring and grading system performs as specified, and the print-to-PDF export is functional.
